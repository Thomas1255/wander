# Wander

Wander is a collaborative travel companion for planning trips with friends and
exploring destinations together.

It is being built around shared place collections, daily itineraries, and maps.

Currently in early development.

Phase 1 includes cinematic destination previews and clearly labeled sample trips.
The current Paprika palette is a visual trial awaiting review.

See the [development guide](docs/development.md) for local setup and verification.
